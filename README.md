# Intro : 
this repo contains the work done in Lab1 of the Collaborative tools course.the goal of the lab was to build a small Python program step by step and to practice the basic git workflow:creating a local repository,saving versions usin commits,and synchronizin with githubb.
the program is called "My Study Assistant*".it is a small console program that greets the student,asks for their first name,the subject they re studyin,and how long they plan to study.all that in 1 file called "main.py"
_____________________________________
# Versions V1 to V4
The `main.py`file was improved 4times(4 versions).in each version is a separate Git commit:

V1 = "1 - initial version"(initial welcome message and a "Good luck with your studying!" line.)

V2 = "V2 - add the user first name"(The program asks for the user's first name and uses it in the greeting.this version and V1 were sent to GitHub with the first push)

V3 = "V3 - add the subject"(the program also asks which subject the user is studying.edited and committed this version on pc, then sent it to GitHub with "git push".

V4 = "V4 - add the study duration"tThe program asks for the study duration in minutes and prints a final goal.created locally thenn pushed with git push)
